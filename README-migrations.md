# TopShelfDeveloper migration runner

Development-only manual ECS runner. Required environment variables: EXPECTED_DATABASE, DB_HOST, DB_PORT, DB_USER, DB_PASSWORD. Set EXPECTED_DATABASE to TopShelfDeveloper. Inject credentials through ECS Secrets Manager; never commit credentials. Add sequential immutable .sql files in migrations/, one SQL statement per file. Applied filenames and checksums are stored in topshelf_schema_migrations, leaving the existing schema_migrations table untouched. Connections verify TLS using the AWS RDS certificate bundle. MySQL DDL is not generally transactional: review and back up before running. The manually dispatched GitHub Actions publish workflow builds the image; ECS execution is a separate manual step. For JSON Secrets Manager secrets, map DB_PASSWORD to the password key with the :password:: ARN suffix.
